# 🦅 Avito Sniper Bot (Railway Production Build)

Асинхронный Telegram-бот на Python (`aiogram 3.x`) для мониторинга новых объявлений на Авито в реальном времени и автоматической отправки первого сообщения продавцу.

## Что исправлено в этой сборке для Railway
1. **Удалён `runtime.txt`** — сборщик Railway больше не падает с ошибкой `mise: No GitHub artifact attestations found`.
2. **Обход TLS-защиты Авито (`curl_cffi`)** — парсер и модуль отправки сообщений маскируются под браузер Google Chrome и работают через ваш `PROXY_URL`.
3. **Автоочистка переменных в `config.py`** — случайные пробелы при вставке токена или прокси в Railway Variables больше не вызывают ошибок.
4. **Автосоздание папки для БД (`DB_PATH`)** — корректная работа с постоянным диском Railway (`/data/avito_bot.db`).
5. **Резервная отправка уведомлений без фото** — если Telegram не сможет скачать превью-картинку с Авито, карточка всё равно придёт текстом.

## Переменные окружения в Railway (Variables)
- `BOT_TOKEN` — токен бота от `@BotFather`
- `ADMIN_IDS` — ваш цифровой Telegram ID из `@userinfobot`
- `PROXY_URL` — ваш приватный российский прокси в формате `http://логин:пароль@ip:порт`
- `CHECK_INTERVAL_SEC` — интервал проверки выдачи в секундах (рекомендуется `12` или `15`)
- `DB_PATH` — путь к базе данных (например, `/data/avito_bot.db`, если подключен Volume `/data`)
