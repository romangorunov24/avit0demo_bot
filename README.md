# 🦅 Avito Sniper Bot (Telegram + Avito Monitor & Auto-Reply)

Асинхронный Telegram-бот на Python (`aiogram 3.x`) для мониторинга новых объявлений на Авито в реальном времени и автоматической отправки первого сообщения продавцу.

## 🚀 Быстрый запуск (локально или на сервере / Railway)

### 1. Подготовка настроек
1. Скопируйте файл `.env.example` и переименуйте его в `.env` (на хостингах вроде Railway/Render/Amvera переменные добавляются в разделе **Variables / Переменные окружения**).
2. Заполните обязательные поля:
   - `BOT_TOKEN` — токен вашего бота от `@BotFather`.
   - `ADMIN_IDS` — ваш цифровой Telegram ID (узнать можно в `@userinfobot`). Только пользователи из этого списка имеют доступ к боту.
   - `PROXY_URL` — (рекомендуется) HTTP/SOCKS5 прокси в формате `http://user:pass@ip:port`.
   - `CHECK_INTERVAL_SEC` — интервал проверки выдачи в секундах (по умолчанию `5`).

### 2. Установка и запуск
```bash
pip install -r requirements.txt
python main.py
```

Если загружаете проект на **Railway / Render / Heroku**, файл `Procfile` уже настроен (`worker: python main.py`) — платформа запустит бота автоматически после добавления переменных окружения.

## 🔗 Как привязать аккаунт Авито
В главном меню бота откройте **«👤 Аккаунт Avito и Автоответ»**:
- **Вариант А (Официальный API Авито — для бизнес/профи аккаунтов):** укажите `AVITO_USER_ID` и `AVITO_ACCESS_TOKEN` в `.env`.
- **Вариант Б (Через Cookies браузера):** авторизуйтесь на `avito.ru`, экспортируйте cookies в формате JSON через расширение `Cookie-Editor` и отправьте их боту в разделе «🍪 Загрузить Cookies Avito».

> **Важно:** При первом добавлении нового поиска бот сначала запоминает текущие объявления на странице (чтобы не спамить по старым публикациям и сразу рассчитать среднюю рыночную цену), а затем мгновенно реагирует на каждое **новое** объявление.
