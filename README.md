# Avito Sniper Pro — Telegram-бот мониторинга объявлений

Бот следит за новыми объявлениями Авито по заданным условиям и присылает карточки в Telegram. При включённом автоотклике он сам пишет продавцу выбранное вами сообщение.

## Что умеет
- **Поиск по параметрам** (кнопка «🧭 Поиск по параметрам»): город → модель → объём памяти → цена → слова. Ссылку на Авито бот собирает сам.
- **Поиск по готовой ссылке** с Авито («➕ Добавить поиск») для любых других случаев.
- Фильтры: мин./макс. цена, объём памяти, плюс-слова (хотя бы одно), стоп-слова, только частники / только магазины, чёрный список продавцов.
- **Автоотклик**: шаблон сообщения с вариациями `{Здравствуйте|Добрый день}` и переменными `{title}`, `{price}`, `{price_bargain}`. Три шаблона: обычный, с торгом, про доставку. Шаблон можно задать для каждого поиска отдельно.
- Лимиты откликов в час и в сутки, пауза между отправками, защита от повторного сообщения по одному объявлению и одному продавцу, тихие часы, автоотключение при ответах Авито 401/403.
- Метка «снайпер-цена», избранное, история отправленных сообщений.

## Запуск (Windows)
1. Установите Python 3.11+.
2. Получите новый токен бота у @BotFather. **Старый токен из исходного архива считается скомпрометированным: его нужно отозвать (`/revoke`).**
3. Запустите `start_bot.bat`. При первом запуске он создаст `.env`. Заполните:
   - `BOT_TOKEN` — токен бота;
   - `ADMIN_IDS` — ваш Telegram ID (узнать у @userinfobot). **Обязательно: без него бот не запустится.** Через `/grant ID` администратор выдаёт доступ другим людям.
4. Пока `PROXY_URL` пустой, бот выходит в сеть с вашего ПК. Для запуска на зарубежном сервере нужен российский прокси.
5. Откройте бота в Telegram, нажмите `/start`.

## Как подключить аккаунт Авито
Раздел «🤖 Автоотклик и Аккаунт» → «Подключить Avito с ПК». Бот просит cookies сессии (экспорт расширением Cookie-Editor). Бот сохраняет все cookies домена avito.ru (в том числе антибот-токены Авито), хранит их в базе в зашифрованном виде, а сообщение с ними удаляет из чата. Длинный JSON, который Telegram режет на части, склеивается автоматически.

## Важно знать (риски и ограничения)
- **Правила Авито.** Авито запрещает автоматизированный сбор данных и автоматические рассылки. Аккаунт, с которого пишет бот, могут ограничить или заблокировать. Меры в боте (лимиты, паузы, отключение при 401/403) риск снижают, но не убирают. Используйте отдельный, не критичный для вас аккаунт.
- **Автоотклик держится на недокументированных адресах Авито.** Официальный API (api.avito.ru) позволяет только отвечать в уже существующих чатах, начать диалог по объявлению он не умеет. Поэтому бот использует внутренние адреса сайта (список в начале `services/avito_messenger.py`). Заранее проверить их без реального аккаунта нельзя. Каждый шаг отправки пишется в консоль (статус и начало ответа), а причина неудачи показывается в карточке и в «📜 Журнале откликов». Если Авито поменяет адреса, правится только список констант вверху файла.
- **Неофициальный доступ.** Бот читает страницы выдачи и обращается к внутренним адресам сайта. Когда Авито меняет разметку или внутренний API, бот перестаёт находить объявления или отправлять сообщения. Потребуется доработка.
- **Скорость.** Выдача проверяется раз в ~90–105 секунд (`CHECK_INTERVAL_SEC`), плюс паузы автоотклика. Это минуты, а не секунды. Уменьшение интервала повышает риск блокировки.
- **Память и цвет** определяются по заголовку и короткому описанию из выдачи. Если характеристика указана только в полном тексте объявления, бот её не увидит. Цвет и состояние задавайте плюс-словами.
- **Выбор города** работает для городов из списка и по написанию названия; остальные города — через готовую ссылку. Ссылки вида `avito.ru/<город>/telefony?q=...` собраны по общему формату Авито и в реальном Авито из этой среды не проверялись.
- Облачный запуск (Railway): диск временный, база и ключ шифрования пропадут при пересборке. Нужен постоянный том или запуск на своём ПК.

## Что исправлено по сравнению с исходной версией
**Безопасность**
- Бот больше не открыт для всех при пустом `ADMIN_IDS`; `/grant` и `/revoke` доступны только администратору.
- Добавлена проверка владельца поиска: другой пользователь не может смотреть, менять, запускать и удалять чужие поиски.
- Ссылки поиска принимаются только на `avito.ru`; cookies отправляются только на `avito.ru`.
- Cookies шифруются в базе (Fernet), старые записи шифруются при запуске; сообщение с cookies удаляется из чата.
- Из `.env.example` убран токен.
- В справке убраны обещания «бана не будет».

**Ошибки логики**
- Кнопка «Отвязать аккаунт» падала с ошибкой.
- Тестовая проверка помечала лоты просмотренными, и реальный мониторинг их пропускал.
- Сбой в одном поиске останавливал проверку остальных поисков.
- Лот помечался просмотренным до отправки карточки; при сбое Telegram он терялся.
- Тихие часы считались по времени сервера; теперь по `TZ_NAME` (по умолчанию Москва).
- Кнопка «Отправить сейчас» не проверяла дубли, лимиты и cooldown продавца и срабатывала дважды при двойном нажатии.
- Пропадала кнопка «Продавца в ЧС» после смены текста.
- Шаблон «За … ₽» при отсутствии цены давал бессмысленную фразу.
- Спецсимволы в ответе ломали HTML-разметку.
- Выбор города, модели и объёма памяти внутри бота (по пункту 3 ТЗ).

## Что исправлено во второй проверке
**Автоотклик**
- Бот сохранял только 9 cookies из экспорта и выбрасывал остальные (в том числе антибот-токен Авито). Теперь сохраняются все cookies avito.ru.
- Кнопка «📨 Отправить это сообщение» отправляла новый случайный текст, а не тот, что виден на карточке после «💸 С торгом» или «📦 Доставка». Теперь уходит именно показанный текст.
- Ответ Авито в виде HTML (страница входа, капча) давал вводящую в заблуждение ошибку «сеть». Теперь он распознаётся, а успехом считается только корректный ответ без поля ошибки.
- Сбой сети или ответ 5xx до отправки текста повторяются до 3 раз. После начала отправки повтор запрещён, чтобы не отправить дубль продавцу.
- Ответ Авито 429 ставит автоотклик на паузу 30 минут, а не продолжает слать запросы.
- После ответа 401/403 автоотклик выключался в базе, но остальные лоты того же прохода всё равно пытались отправиться.
- Если карточка в Telegram не доставилась, а сообщение продавцу уже ушло, карточка теперь пишет «уже отправлен ранее», а не «антиспам».
- Журнал откликов показывает причину неудачи.
- Проверка сессии сначала спрашивает у Авито профиль, при смене адреса проверяет по странице профиля. Нажатие «🔄 Проверить сессию» отвечает сразу.

**Мониторинг**
- Ссылка с чужой сортировкой (`s=1`) дополнялась вторым `s=104`, и новые лоты можно было не увидеть. Теперь значение заменяется.
- Страница с капчей или защитой распознаётся: включается пауза парсера и пишется понятное предупреждение, а не молча «0 лотов».
- Подпись к фото ограничена 1024 символами: описание сокращается, а если не помогает, карточка уходит текстом.
- Включён режим WAL в SQLite (меньше ошибок «database is locked»), интервал проверки не меньше 30 секунд, аварийная остановка воркера пишется в лог.

**Интерфейс**
- Нажатие кнопки главного меню или команды посреди мастера создания поиска или настройки принималось за ответ (например, название поиска «🤖 Автоотклик и Аккаунт»). Теперь ввод сбрасывается.
- «Отвязать аккаунт» и «Разблокировать продавца» отвечали на нажатие дважды; после снятия последнего продавца из ЧС экран не обновлялся.
- Удаление из избранного стирало весь список; теперь список обновляется.
- Лимиты, пауза, интервал повтора, порог выгоды, тихие часы и шаблоны проверяются: при неверном вводе бот переспрашивает, а не пишет «сохранено». После сохранения шаблона показывается пример сообщения.
- Мин/макс цена проверяются на числа и порядок, удаление поиска требует подтверждения, кнопка «Ещё текст» учитывает шаблон конкретного поиска.
- `start_bot.bat` сообщает, если Python не установлен или зависимости не поставились.

## Безопасность и прокси (третья проверка)
**Исправлено**
- Логин и пароль прокси скрываются в логах и в сообщениях об ошибках. Пароль со спецсимволами (`@ # : /`) в формате `хост:порт:логин:пароль` разбирается верно.
- Ответ диагностики сети экранируется: данные внешнего сервиса не могут сломать разметку или вставить свою.
- Ссылка лота, пришедшая из выдачи, проверяется на avito.ru до использования в кнопке и при отправке с cookies.
- Слишком длинный идентификатор продавца ломал клавиатуру карточки (лимит Telegram 64 байта) и карточка не доходила. Теперь кнопка «Продавца в ЧС» в таком случае просто не показывается.
- Поиски пользователя с отозванным доступом больше не обрабатываются: ни карточек, ни сообщений продавцам с его cookies.
- Автоотклик и кнопка «Отправить» работают через общую очередь: нет двойной отправки и превышения лимита при одновременном срабатывании.
- Карточка, которая не доставляется постоянно (бот заблокирован), пропускается после 3 попыток, а не повторяется вечно.
- Не больше 15 поисков на пользователя (у администратора без ограничения), общий обработчик ошибок не оставляет кнопки «зависшими».
- Если ключ шифрования потерян, в лог пишется понятная причина, а не молчаливое «аккаунт не привязан».

**Какой прокси брать**
- Российский IP, **статический (не ротируемый)**. Сессия Авито привязана к IP: при смене адреса на каждый запрос Авито отвечает 403 и автоотклик отключается.
- Лучше заходить в Авито в браузере через этот же прокси, когда экспортируете cookies.
- Если у прокси вход по IP, добавьте IP вашего сервера в белый список.
- Укажите постоянный `COOKIES_KEY` в `.env`/переменных окружения и постоянный том для папки с базой, иначе после пересборки cookies придётся подключать заново.

## Проверка
Автотесты: `python -m pytest tests`. В `tests/test_autoreply.py` автоотклик проверяется от появления нового лота до записи в журнал (отправка один раз, переключатели, повторы, 401/403, 429, лимиты, повторная доставка карточки), а также отправка с подменённым Авито, разбор cookies, парсер и сброс ввода по кнопке меню.

**Что не проверено.** Работа против настоящего Авито и настоящего Telegram. Тесты используют подмену Авито, поэтому они подтверждают логику бота, но не то, что внутренние адреса Авито принимают сообщение. Первую отправку проверьте на одном реальном лоте и посмотрите консоль бота. Сам `tests/test_flow.py` (обработчики Telegram) при подготовке этой версии запустить не удалось, его нужно прогнать у себя.
