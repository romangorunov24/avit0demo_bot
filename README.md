# Avito Sniper Pro — Telegram-бот мониторинга объявлений

Бот следит за новыми объявлениями Авито по заданным условиям и присылает карточки в Telegram. При включённом автоотклике он сам пишет продавцу выбранное вами сообщение.

## Что умеет
- **Поиск по параметрам** (кнопка «🧭 Поиск по параметрам»): город → модель → объём памяти → цена → слова. Ссылку на Авито бот собирает сам.
- **Поиск по готовой ссылке** с Авито («➕ Добавить поиск») для любых других случаев.
- Фильтры: мин./макс. цена, объём памяти, плюс-слова (хотя бы одно), стоп-слова, только частники / только магазины, чёрный список продавцов.
- **Автоотклик**: шаблон сообщения с вариациями `{Здравствуйте|Добрый день}` и переменными `{title}`, `{price}`, `{price_bargain}`. Три шаблона: обычный, с торгом, про доставку. Шаблон можно задать для каждого поиска отдельно.
- Лимиты откликов в час и в сутки, пауза между отправками, защита от повторного сообщения по одному объявлению и одному продавцу, тихие часы, автоотключение при ответах Авито 401/403.
- Метка «снайпер-цена», избранное, история отправленных сообщений.

## Запуск (Windows)
1. Установите Python 3.11+.
2. Получите новый токен бота у @BotFather. **Старый токен из исходного архива считается скомпрометированным: его нужно отозвать (`/revoke`).**
3. Запустите `start_bot.bat`. При первом запуске он создаст `.env`. Заполните:
   - `BOT_TOKEN` — токен бота;
   - `ADMIN_IDS` — ваш Telegram ID (узнать у @userinfobot). **Обязательно: без него бот не запустится.** Через `/grant ID` администратор выдаёт доступ другим людям.
4. Пока `PROXY_URL` пустой, бот выходит в сеть с вашего ПК. Для запуска на зарубежном сервере нужен российский прокси.
5. Откройте бота в Telegram, нажмите `/start`.

## Как подключить аккаунт Авито
Раздел «🤖 Автоотклик и Аккаунт» → «Подключить Avito с ПК». Бот просит cookies сессии (экспорт расширением Cookie-Editor). Cookies хранятся в базе в зашифрованном виде, а сообщение с ними бот удаляет из чата.

## Важно знать (риски и ограничения)
- **Правила Авито.** Авито запрещает автоматизированный сбор данных и автоматические рассылки. Аккаунт, с которого пишет бот, могут ограничить или заблокировать. Меры в боте (лимиты, паузы, отключение при 401/403) риск снижают, но не убирают. Используйте отдельный, не критичный для вас аккаунт.
- **Неофициальный доступ.** Бот читает страницы выдачи и обращается к внутренним адресам сайта. Когда Авито меняет разметку или внутренний API, бот перестаёт находить объявления или отправлять сообщения. Потребуется доработка.
- **Скорость.** Выдача проверяется раз в ~90–105 секунд (`CHECK_INTERVAL_SEC`), плюс паузы автоотклика. Это минуты, а не секунды. Уменьшение интервала повышает риск блокировки.
- **Память и цвет** определяются по заголовку и короткому описанию из выдачи. Если характеристика указана только в полном тексте объявления, бот её не увидит. Цвет и состояние задавайте плюс-словами.
- **Выбор города** работает для городов из списка и по написанию названия; остальные города — через готовую ссылку. Ссылки вида `avito.ru/<город>/telefony?q=...` собраны по общему формату Авито и в реальном Авито из этой среды не проверялись.
- Облачный запуск (Railway): диск временный, база и ключ шифрования пропадут при пересборке. Нужен постоянный том или запуск на своём ПК.

## Что исправлено по сравнению с исходной версией
**Безопасность**
- Бот больше не открыт для всех при пустом `ADMIN_IDS`; `/grant` и `/revoke` доступны только администратору.
- Добавлена проверка владельца поиска: другой пользователь не может смотреть, менять, запускать и удалять чужие поиски.
- Ссылки поиска принимаются только на `avito.ru`; cookies отправляются только на `avito.ru`.
- Cookies шифруются в базе (Fernet), старые записи шифруются при запуске; сообщение с cookies удаляется из чата.
- Из `.env.example` убран токен.
- В справке убраны обещания «бана не будет».

**Ошибки логики**
- Кнопка «Отвязать аккаунт» падала с ошибкой.
- Тестовая проверка помечала лоты просмотренными, и реальный мониторинг их пропускал.
- Сбой в одном поиске останавливал проверку остальных поисков.
- Лот помечался просмотренным до отправки карточки; при сбое Telegram он терялся.
- Тихие часы считались по времени сервера; теперь по `TZ_NAME` (по умолчанию Москва).
- Кнопка «Отправить сейчас» не проверяла дубли, лимиты и cooldown продавца и срабатывала дважды при двойном нажатии.
- Пропадала кнопка «Продавца в ЧС» после смены текста.
- Шаблон «За … ₽» при отсутствии цены давал бессмысленную фразу.
- Спецсимволы в ответе ломали HTML-разметку.
- Выбор города, модели и объёма памяти внутри бота (по пункту 3 ТЗ).

## Проверка
Автотесты (`python -m pytest tests`): 30 проверок — фильтры памяти и слов, тихие часы, проверка ссылок, шифрование и миграция cookies, права доступа, весь сценарий «Поиск по параметрам» через обработчики Telegram, рассылка карточек и повторная доставка при сбое. Работа против настоящего Авито и настоящего Telegram в этой среде не проверялась.
